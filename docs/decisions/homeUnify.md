# Home unify (wave 28, HOM-01, HOM-22, HOM-23): decisions

Supersedes the deck part of [homePages.md](homePages.md) (the separate "Pages" surface, deck dots, the add-page "Scroll or Paginated" question and `pagesModeChosen`). The rest of homePages.md (Order, ColumnFill, hotspots, Glance on/off) stands.

Owner: "A user can only turn on more page(s) - paginated or continuous; and manually add icons to it by long press -> edit and selecting apps and widgets to add to it. And the way that opens is incorrect, the calm home just as a regular home and the rest are regular pages. Right now there is a page indicator, and when I swipe to go right, this app drawer opens up and has its own dots in a new place - that's wrong also."

## Why it was wrong (wave 26)
`HomeScreen` swapped two whole surfaces with a cross-fade (`shownSurface`: Glance or Pages) and a hand written `deckSwipe`. Glance drew its own "deck dots" above its indicator; the pages drew their own dot row with a leading Glance dot. Two surfaces, two sets of dots in two places, and a pop-in that read like a second app drawer.

## The model
- The home is ONE `HorizontalPager` in `HomeScreen` (tag `home.pager`). Its stops: `[Glance, when on] [pages stop]`. `HomeShown` is no longer state: `landing` is derived from the pager's current stop (`HomeDeck.surfaceAt`). Swiping, the page dots, the Home button and the add flows all move that one pager (`showStop`, `showSurface`, `showDot`).
- The pages stop is the existing grid (`GridHome`, its own pager nested in the outer one) or, in Continuous, `ColumnScrollHome` (the Windows 8 column fill, a horizontal scroll). Forward from Glance is the outer pager's own drag (live). Back from the first grid page or the start of the scroll: both are scrollables that keep their drag, and the nested-scroll hand-over to the outer pager is not dependable (a probe with a plain scroll and a plain pager inside a pager did not hand over in a Robolectric swipe), so the existing `deckSwipe` (a swipe towards the Comms edge at the first page / start of the scroll, taken in the Initial pass) runs on release and moves the pager to Glance (`showStop(0)`); on release so the pager that took the first pixels of the same drag settles first and does not interrupt the move. With Glance off the same swipe opens Comms as before. Wallpapers stay separate (the Glance page draws the Glance background, the pages stop the Pages one). Each pager page has exactly ONE root node (the pages stop is wrapped in a Box): a lazy page with several roots is not placed.
- Edit mode, drag, folders and widgets are untouched: the outer pager's user scroll is off while editing, an item drag is consumed by the grid before the pager sees it, and the edge drags for Comms and Recents still win in their edge zone (they take the event in the Initial pass above the pager).

## Pages setting (`HomePages`: Off, Paginated, Continuous)
- Ground Control, Home screen, row "Pages" (three visual choices); the long-press quick sheet has three chips (tags `quick.pages.Off|Paginated|Continuous`) under the Glance tile.
- Off: no extra pages. With Glance on, home is Glance only. With Glance off, home is the first page (empty, editable, no indicator). The other pages stay stored (`HomeScreen.pages` shows the first page only, `preserve` keeps the rest) and come back when Pages is turned on. Default for a new install: Off.
- Paginated: regular pages after Glance. Continuous: after Glance the one scroll surface; there is no "Add page" in Continuous (one surface), Edit home works, and an empty scroll shows the same "Long press to add apps" hint as an empty page.
- "Add page" no longer asks anything and is offered only in Paginated (Ground Control row, quick sheet button, the edit card); with Off or Continuous the Pages setting is the one switch that turns pages on (review 2: it used to flip the setting silently). It adds the page and goes to it. `PagesModeDialog` and the `pagesModeChosen` flow are deleted. "Edit home" (quick sheet, Ground Control) with Pages Off turns Paginated on first and says so in one line (a toast), then enters edit mode on page 1; placing an item from Glance does the same so it can always be seen.
- Migration (`HomeModelMigration.pagesMode`, JVM-tested): a stored `homePages` wins; the old `homeScroll` Continuous (it counted as a choice) gives Continuous; a chosen Paginated gives Paginated; nothing chosen gives Paginated when the home already has built pages (more than one page, or an item), else Off, so no page is ever hidden by the update. An imported settings file from before wave 28 follows the same rule against the layout of the same file (`SettingsCodec.decode(settings, layoutHasPages)`); its retired keys are read, never kept as unknown fields. `LauncherStores` settles the unchosen case once the layout is known (`migratePages`); the old keys `homeScroll` and `pagesModeChosen` are only a migration input and are removed on the next save. `HomeScroll` is gone.

## One indicator
- `PageIndicator` (feature-grid) is the only indicator. `HomeScreen` draws it once, at one fixed place (bottom centre, 4 dp above the safe area), above the pager, so it cannot jump or duplicate. Its row: the Comms glyph (the Glance indicator's first glyph, 48 dp, tag `glance.indicator.launchpad`), the house = the Glance stop (tag `pages.glancedot`, lit and not interactive while Glance shows), then one dot per page (Paginated, tag `pages.dot.N`) or one for the scroll (Continuous), then the right-hand dots (Recents, dock, tags `glance.indicator.right.*`). On Glance it dims after a few quiet seconds (motion preference respected, 0 ms when reduced); on pages it stays lit. Every node of the row carries the stop position ("Page 2 of 4" counts Glance as stop 1), so TalkBack hears the same count as the eye sees.
- `GridHome` has `drawIndicator = false` when hosted (kept true for a bare grid); `GlanceSurface` has `indicator = false` when hosted (true for a bare Glance, one stop). The deck dots (`DeckDots`) and `GlanceIndicator` are deleted. The old "Page options" menu glyph of the page dots is replaced by the Comms glyph (page options remain on a long press of the empty page).
- With vertical paging the home still pages sideways between Glance and the pages; the indicator is the bottom row in every case.

## Navigation
- Home button: stop 0 (Glance when on, else page 1). Keyboard page chords still move the grid pager; Ctrl+Shift+arrows unchanged. Order Right to left mirrors the outer pager (`reverseLayout`), the Glance row and every swipe; physical coordinates as before.

## Not done / device only
- A real AppWidget bind through the widget picker is not driven under Robolectric (the flow test places the Files panel tile through the same quick sheet add sheet); touch feel of the nested pager hand-over, inertia of the scroll and real insets need a device.
