# settingsFont (wave 52): Settings home rows, centred capital titles, the UI font

Owner feedback on the One UI Settings home (CFG-21). Nothing here is device verified.

## Decisions
- **"Pages", not "Page 1".** The first row opens the settings of the page you are on; it is named for what it holds (the pages) and its summary says which one: `Page 1 of 3 · Grid`. The category title is the English key "Pages" (`OneUiModel.PAGE`); the old "Page N" titles are no longer recognised (owner policy: for things newly specified keep only the owner's option).
- **"Side panel", not "Comms".** The right-hand panel can hold widgets as well as Comms, so the row, its page title and its search keyword set are named by the container (`OneUiModel.SIDE_PANEL`). The sections inside the panel keep their names. "comms", "widgets", "panel" and the older "launchpad" still find every row of the category (`SettingsIndex.CATEGORY_KEYWORDS`, `ALIASES`). Summary (`sidePanelSummary`): `Comms · 100%`, `Widgets · 2`, or both joined by a comma. The widget count is a parameter of `settingsSummaries` (`sidePanelWidgets`, 0 by default): the widgets feature in `feature-launchpad` is built in another stream, so the call in `HomeScreen` does not pass it yet. Pass the placed-widget count there when the two branches meet.
- **Workspaces is a top-level row** in the first card (Pages, Home screen, Workspaces), summary `3 workspaces`, opening the Workspaces page with the active workspace under its title. It is a category made of the one pane, so `OneUiCategoryPage` now honours the pane's `bare` flag and live subtitle (it did neither before; Hidden apps was the only such category and is not bare). The old entry under "Desktop & dock" is removed; App groups, Dock and the external display page stay there (the owner did not ask for them to move).
- **Titles: centred, capitals, Space Grotesk.** One composable (`OneUiTitleText`) draws the large title, the collapsed small title and the dialog titles. The text shown is `titleCaps(title)` (`String.uppercase` with the app language's locale: German sharp s, Turkish dotted i; Arabic, Hindi and CJK have no case and are unchanged). The semantics keep the plain title as the node's text and a heading role, so a screen reader reads words, not capital letters, and every lookup by the plain title keeps working; the shown capitals are exposed to tests through `ShownTitleKey`. The large title was already vertically centred in the band (wave 46); it is now centred horizontally too (its column is centred and the text is centre-aligned). Titles are always Space Grotesk, whatever UI font is chosen (the owner asked for titles in Space Grotesk).
- **UI font.** `LauncherPrefs.uiFont` (a string id, default `space_grotesk`; the ids are `UiFonts.IDS` in core-data, the families `FontCatalog.entries` in core-design, and a test keeps the two lists equal). It is read in the activities and `HomeScreen` into `HyleFont`, and `SphereTheme` builds the Material typography from that family, so every `Text` below the theme (labels, Radar, sheets, the Glance clock text, icon labels on home) follows it with no restart. Choices: Space Grotesk, System default, Inter, Manrope, DM Sans, JetBrains Mono, Atkinson Hyperlegible, Lexend. The Look page shows them as cards (`FontChoice`, `VisualChoice`), each rendering "Liftoff 12:30 Aa" in its own family; the Look summary names the font. Stored in `launcher_prefs`, so the settings file, Android backup and the "everything is carried" test already cover it; a `.liftofftheme` pack may carry an optional `uiFont` (unknown ids refuse the pack; a pack without it leaves the font alone). Stored as written, read as the default when unknown (`UiFonts.normalize`, `FontCatalog.normalize`), so a hand-edited file never breaks the UI.
- **Fonts and size.** Open-licence TTFs under `core-design/src/main/res/font`, cut to the Latin range with variable fonts keeping only the weight axis (Atkinson ships two static files); licences in `docs/licenses` (SIL OFL 1.1; there was no third-party notices file to extend). They are looked up by name (`Resources.getIdentifier`), so a file that is missing from a build, or fails to load, makes the family the platform sans: the picker and the theme still work. A `res/raw/keep_fonts.xml` keeps them if a resource shrinker is ever switched on (none is today). Raw size of the eight files: about 700 KB (APK size delta reported in the status file).

## Not done
- The curved ring labels of the wheel drawer and the hot corner labels draw with a `Paint`, not a theme `Text`, so they keep the platform font. Changing them touches `WheelDrawer.kt` and `RingLabels.kt` that other streams edit.
- Characters outside the Latin range (Cyrillic, Greek, Devanagari, CJK, Arabic) are not in the bundled files and fall back to the system font per glyph.
