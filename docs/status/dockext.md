# Status: dock, workspaces and external display (wave 2, stream "dockext")

Nothing here is device-confirmed. "built" means it compiles, is wired into the live screens or activities, and is covered by JVM or Robolectric tests; it has not run on a device or on a real external display. Wave 1 notes are in `dock.md` and `desktop.md`; this file supersedes the rows for the IDs below.

The home-page stand-in for next/previous workspace was removed: those keys now step workspaces. The same shortcuts reach the desktop surface's own dock through `DesktopActivity.onKeyDown`. ## Shared-file edits (all small)

- `app/.../HomeScreen.kt`: the command handler's `else` now calls `dockController.handle(c)` (the two workspace stand-in lines were removed), `LastTouch` is built by `homeLastTouch`, and the search hub gets `dockSearchProvider(context)`.
- `app/.../ui/SettingsCategories.kt`: one line to add the "Desktop & dock" category and one to keep it in the reorganised list.
- `app/src/main/AndroidManifest.xml`: a `<layout>` child on `DesktopActivity`.
- New files in `app/.../ui`: `DesktopDockProvider.kt`, `DesktopSettingsPane.kt`; `DockLayer.kt` (own area) grew the widget hooks, group shelf, panel host and Radar provider.
