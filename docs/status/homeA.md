# Home surfaces, wave 2 (stream "homeA"): status

Status vocabulary: built = compiles and covered by JVM or Robolectric tests; partial = some of it built or wired; not started; unmet. Nothing here is device-confirmed.

New code: `core-catalog` `HomeWiring.kt` (span grid, reflow, drop-onto intent, rekey, resolve, startup restore plan, hidden-apps view) and `HomeExtrasStore.kt`; `feature-grid` `HomeExtrasUi.kt`, `GridSpanBridge.kt`, `ScrollExtrasBand.kt`, `IconSources.kt`, `HomeItemsDialogs.kt`; `app` `HomeItemsHost.kt`. Small additive edits in the shared files `GridHome.kt`, `HomeScreen.kt`, `HomeQuickSheet.kt`, `FolderUi.kt`, `AppIcon.kt`, `Icons.kt`, `CatalogStores.kt`.

How it fits together: folders, shortcut, link, file and widget definitions live in `HomeExtrasStore` (persisted through `HomeStateCodec`); the page order stays in the home layout store and refers to them by their prefixed keys. `HomeScreen` resolves pages against both (`HomeResolve`), reflows grid pages that hold spanning widgets (`SpanReflow`) and hands `HomeItems.homeExtras` to every surface. Entry point for the user: the Home quick sheet (long-press empty space) now has "Widgets, folders and icons".
