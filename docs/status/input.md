# Input stream status (keyboard, pointer, focus, corners, puck)

Nothing here has been run on a device. "built" means it compiles and is covered by unit tests (JVM, plus Robolectric where noted). Facts about hover and controller events reaching the home activity at the screen corners (spikes for INP-16 and INP-20) are still to be checked on a phone.

## Notes for the merge

* Shared-file edits are small hooks: `HomeScreen.kt` (corner set selection, one `LauncherInputWiring` call, long-press gesture override), `SettingsCategories.kt` (five rows), `GridHome.kt` (item modifier, page focus, swipe guard, `GridKeyboardMove` call), plus one-line modifiers in `ListHome`, `XmbHome`, `ContinuousHome`, `Corners`, `HomeGestures`.
* New `LauncherPrefs` fields are at the end of the data class and read with defaults in `LauncherStores`.
* `feature-grid` now depends on `core-input`.
