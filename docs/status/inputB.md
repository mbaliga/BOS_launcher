# Input stream, wave 2 (coverage across surfaces, menus, shortcut persistence, accessible order)

Nothing here is device-confirmed. "built" means it compiles and is covered by JVM unit tests or Robolectric tests. Compose glue that no test drives is called out in each note. Statuses were only raised where the acceptance criteria are met in code and tests.

## Not done in this stream

* Dock rail and panel dialogs (dock stream files) do not get the controller window hook.
* The legacy quick sheet and the Launchpad row menus are not generated from `ContextMenus` (Launchpad has its own tested parity model).
* `docs/SPEC_STATUS.md` was not edited.

## Known failing check outside this stream

`core-design` `TranslationCoverageTest.CFG_19_everyLiteralUsedInTheSourceExistsInAllEightLanguages` failed before this wave (other streams' strings: backup pane, safe mode, tags, folder text). The strings this stream added or inherited from wave 1 (shortcut sheet, edit mode toast, drops, corner shortcut picker) are now in `L10nInput.kt` in all eight languages.
