# Launchpad stream status (wave 2)

Status words: built = compiles and is unit or Robolectric tested; partial; not started; unmet. Nothing is
device-confirmed; the steps for a device are in `docs/device-checklist-launchpad.md`.

Wave 2 wired the wave-1 logic into the live screens and closed the gaps listed below.

## Known failure outside this stream

`./gradlew testDebugUnitTest` reports exactly one failure, this one, and it fails identically on the base commit f3ddc0a; every other test and `assembleRelease` pass.


`core-design` `TranslationCoverageTest.CFG_19_everyLiteralUsedInTheSourceExistsInAllEightLanguages` lists about 230 strings from other streams (backup pane, dock, desktop, palette menus, shortcut sheet, safe mode, onboarding) that are missing in the eight languages. They come from files this stream did not touch; every string this stream added is translated (`L10nStrWave2.kt`) and none of them is on the list.
