# Palette (Radar) status, wave 2

Status vocabulary: built = compiles and unit-tested; partial; not started; unmet. Nothing here was run on a device or an emulator; Robolectric tests only cover what is named.

Wave 1 built the engine (`search-engine/.../palette/`, pure Kotlin) and Android adapters (`feature-search/.../palette/`). Wave 2 wired them into the live Radar (`feature-grid` `SearchOverlay.kt` and `HomeScreen.kt`): the live screen still has its own result model (`SearchData`, tiles); the engine is used for app matching, ranking, the stable order, file index, shortcut and command running. `PaletteEngine` and `PaletteSession` themselves are not what the screen runs (see PAL-12).
