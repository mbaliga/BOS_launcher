# Wave 24 stream homeTests: home edit, widgets, stacks, the Files tile and reconcile, on Glance and on Selected apps

This stream adds tests and two code fixes, and checks each ID on the Glance landing (the default since wave 16) and on Selected apps. Decisions: `docs/decisions/homeLandingPlacement.md`. Nothing here was run on a device. Robolectric runs a real `MainActivity`, but it has no compositor and no real widget provider. The statuses below are what this stream supports; `docs/SPEC_STATUS.md` was not edited.

New tests:
- `HomeLandingItemsW24Test` (app, whole app): 7 tests.
- `WidgetEditHandleW24Test` (feature-grid): 4 tests.
- `DockUnavailableW24Test` (feature-dock): 3 tests, one of them a pixel check.
- `HomePlacementLandingTest` (core-data): 3 tests.
- `EditWorkspaceSwitchTest` (core-catalog): 3 tests.

How each surface is reached from Glance, checked in the running app under Robolectric:
- Edit mode: the long-press quick sheet, "Edit home pages".
- Widgets, folders, links, shortcuts, groups and panel tiles: the quick sheet, "Widgets, folders and icons". Placing one now switches to Selected apps, where it is drawn.
- The Files, Usage and Timeline panels: the quick sheet, "Files, usage and timeline".
- The work profile pause: the drawer's Work tab. Glance draws no pause banner, by design.

Nothing in this stream is reachable only from a surface that was removed.
