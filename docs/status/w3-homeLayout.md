# Home surfaces, wave 3 (stream "homeLayout"): status

Status vocabulary: built = compiles and is covered by JVM or Robolectric tests; partial = some of it is built or wired; not started; unmet. Nothing here is device-confirmed; no gesture, widget binding or dock behaviour was run on hardware.

New code: `feature-grid` `HomeInterleave.kt`, `QuickSheetLayout.kt`; `core-catalog` `WidgetStacks.kt`, `FolderSearchProvider.kt`; `feature-dock` `DockFootprint.kt` and `HomeItemPins` (in `DockModel.kt`); `core-design` `L10nW3homeLayout.kt`. Small additive edits in the shared files `ListHome.kt`, `XmbHome.kt`, `ContinuousHome.kt`, `GridHome.kt`, `GridSpanBridge.kt`, `HomeScreen.kt`, `HomeItemsHost.kt`, `HomeQuickSheet.kt`, `MainActivity.kt`, `DockLayer.kt`, `DockHost.kt`, `HomeWiring.kt`, `HomeItems.kt`.

Tests: `HomeLayoutW3Test` (core-catalog: stacks, span-aware drop index, folder provider, group item), `HomeInterleaveTest` and `HomeLayoutW3UiTest` (feature-grid: interleave rules, List/XMB/DSi rendering, HOM-19 at 14 window sizes, quick sheet rules), `HomeLayoutW3DockTest` (feature-dock: pins for home items, rail footprint).
