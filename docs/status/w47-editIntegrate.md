# Wave 47: editIntegrate (HOM-07, HOM-12, NFR-13)

The four wave 45 edit streams (handles, action bar and sheet, chrome, page editor layout) were built in parallel. This wave makes them one editor. Decision record: `docs/decisions/editIntegrate.md`. Nothing here is device verified.

| ID | Status | Note |
| --- | --- | --- |
| HOM-07 | built, feel unverified | The bar's Resize no longer starts a mode: the handles of a selected widget are always shown; Resize focuses them and announces "Resize handles active". The old `resizing` mode, its `HomeExtras` fields and the in-widget Done are gone. Size presets in the widget sheet are clamped by the provider limits (`PresetClamp`, the handles' `CellLimits`) with a reject buzz and the note "Not available for this widget". ## What was integrated or removed
- `HomeItemSelection`, `HomeEditBar` (four pills), `HomeEditHandle.kt` / `EditHandleBox` (remove badges on icons, folders, tiles), `HomeItems.resizing` and `startResize` as a mode, `HomeExtras.resizing / onResize / onResizeDone`, the bar's fixed reserves (64 dp, dock + 72 dp), `ColumnScrollHome.onRemove`.
- New: `EditTopBar` and `EditCancelDialog` (extracted from the chrome), `EditChromeGeometry.actionBarReserveDp`, `EditSelectionState.focusResize / dragging`, `EditGridState.layer`, `PresetClamp`, `L10nW47editIntegrate.kt` (3 strings, 8 languages).
- Two real bugs found while writing the flows: (1) the Grid style with Pages Continuous drew every widget twice (the column scroll surface and the HOM-08 band, which is for List, XMB and DSi): two selection frames, two sets of handles; the band is now only for those styles. (2) The handle drag read `positionChange()`, which is zero once an ancestor consumed the move (the scroll surface): the drag stuck at the first step; it now reads the raw change. On the scroll surface the selected widget also needed `childrenOutOfBounds` and a higher z-index so its south handle is not taken by the cell below.
- Old tests changed because the owner's decisions replaced the behaviour: `HomeEditModeTest` (badge test now selects and uses the bar), `WidgetEditHandleW24Test` (fallback button to the bar), `EditChromeW45AppTest` (three badge clicks now long press and the bar's Remove; the page editor now has the same bar with its own title and no tray), `PageEditorAppTest` ed12 and ed13 (the bottom "Add page" pill is gone; the New page card is the one add path), `HomeUnifyFlowTest` and `PagesExplicitW30FlowTest` (Back in the page editor is Cancel and would undo the added app; they use Done), `EditCardAppTest` (Back asks, Keep editing stays, Discard restores), `HomeEditScreenshotTest` (the four-pill bar test now uses `EditTopBar`), `EditChromeW45AuditTest` and `HomeInfoW3AuditTest` (files moved), `PageEditorGeometryTest` pe01c (0.45 instead of 0.38).

## Flows covered in the real app (Robolectric)
`EditIntegrateBase` (run as Paginated left to right, Pages Continuous, and a right-to-left layout with the right-to-left page order): (a) edit entry (bar, tray, hint), long press selects an icon with the bar (no Resize for an icon, no second outline, no badge, no fallback button), a second long press moves the bar to the new item, a tap selects and a second tap deselects, Settings opens the item sheet and the bar stays between the top bar and the tray, Remove with the Undo snackbar and Undo, the top bar's Undo and Redo, Cancel restores the snapshot (confirm), Done saves; (b) widget: tap selects, eight handles (two for a horizontal provider; three on the scroll surface), the bar's Resize announces and keeps the handles, a handle drag shows the ghost and the chip (grid dots on the page grid), release resizes, a neighbour blocks, a provider limit keeps the size and announces, the sheet's presets clamp with the note; (c) page editor from the title (same bar, no tray, strip above, tabs below, live card at least 0.40 of the window between them), reorder (Move later), add a page, delete with Undo, Cancel and Back (confirm only when changed), Done; (d) the hotspot shield is up and the side tray is hidden while editing, taps on the page's corners keep edit mode.
