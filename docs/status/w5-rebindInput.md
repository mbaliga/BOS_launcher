| CFG-01 | partial | The earlier note said no rebind UI existed; the shortcut sheet (opened by the Keyboard shortcuts row in Ground Control and by F1) already listed commands with Change, Unbind and Reset. What was missing is now built on top of it: (1) a clash is no longer only reported, the sheet offers Swap or Cancel (`ShortcutEditor.swap`: the command takes the chord and the one that held it gets the chord the first had, or none; Cancel changes nothing; nothing is taken without the answer); (2) Reset all (`ShortcutEditor.resetAll`, the slot becomes empty so an export carries nothing); (3) per-command Reset no longer silently takes back a default chord another command now holds: it reports the clash and offers Swap or Cancel like a rebind (found in review; `CFG_01_resetNeverStealsAChordAnotherCommandNowHolds`); (4) reserved system chords are refused with their own reason (Alt+Tab, Ctrl+Tab, Alt+F4, Alt+Esc, Ctrl+Esc, Ctrl+Alt+Del, Ctrl+Space) on top of the existing refusals (Meta chords, bare keys, modifier-only). Every row has a Change, Unbind and Reset button; Change captures the next real key chord. Persistence goes through the existing override store (`ShortcutPersistence` into the state file's keyboard slot, exported and imported by `StateCodec`); the sheet takes `reload` and `save` seams so a test can use its own slot. Tests: `ShortcutRebindW5Test` (pure: swap, swap with an unbound partner, cancel, refusal wins over swap, reset one, reset all, reserved chords, restart through the slot), `ShortcutRebindUiTest` (Robolectric: every command listed with its chord, Change captures Ctrl+J from real key events and the registry and slot follow, a clash shows Swap and Cancel and steals nothing until Swap, Alt+Tab refused with nothing saved, reset one and reset all clear the slot), plus the older `ShortcutOverrideStoreTest`. Still open, device only: a real hardware keyboard on a device (the headless test sends synthesized key events), and the SAF export write path was never exercised on a device. The status stays partial for that step only. |
