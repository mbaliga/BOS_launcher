# Wave 7: undoScroll (HOM-12, HOM-16, INP-10, CFG-17)

| ID | Status | Note |
| --- | --- | --- |
| HOM-12 | partial | Dock pin changes now share the layout undo (depth 20). `LayoutDockEditSession` (core-catalog) holds one stack; an entry carries a pin change only when that edit changed the pins. A move to the dock (page change plus pin, observed within 400 ms in either order) is one entry, so one undo restores page position and pin, and redo reapplies both. Pin, unpin, move out of dock and dock reorder made while edit mode is on each undo. Rule for a rail edit between two home edits: it is its own entry, undone in order; a layout-only entry never writes the rail; undoing an earlier pin entry after the rail changed uses `DockPinMerge` (remove what the edit added, put back what it removed, keep every other pin and the current order) instead of overwriting. A workspace switch is rebased, not an edit, and pins are only written back to the workspace they came from. Scrolling styles have no page arrangement: their entries are pin-only and undo restores only the rail (tested). Wired in `HomeEditState` (HomeBehaviour.kt) through `WorkspaceHomeDockPins` and one line in HomeScreen. Tests `LayoutDockUndoTest` (JVM, 9). Stays partial: no Robolectric or device run of the real drop onto the rail followed by Undo in edit mode; the 400 ms pairing window is a judgement the owner may want to see on a device. |
| HOM-16 | partial | Scroll offsets are now forwarded from every style that scrolls across: paged grid (already), horizontal continuous grid and horizontal DSi (progress along the grid as 0..1 over two pages, `WallpaperScroll.gridProgress`), XMB category bar (one page per category). Vertical-only styles (list, vertical continuous and DSi) send the fixed centred offset (0.5, no steps), which also clears an offset left by another style. Animations off (`rememberMotionPrefs().reduced`) snaps the forwarded position to the settled page. Public APIs only (`WallpaperManager`). Tests `WallpaperScrollTest` (JVM maths for each style) and `WallpaperScrollUiTest` (Robolectric: effect, disabled, vertical, reduced, horizontal and vertical continuous grid, XMB, option off sends nothing). Stays partial: the effect on a real live or panoramic wallpaper needs a device. |
| INP-10 | built | `ShortcutRegistry.import` now resolves clashes to a fixed point: an unwritten command keeps its binding, between two parts the earlier wins, a dropped part falls back to its default and, if that is taken too, ends unbound. Tests `W7ImportEdgeTest` (the default-taken edge, the free-default fallback, clash with an untouched default, 400 random files: never two commands on one chord and the result re-imports unchanged) beside the existing import audit tests. |
| CFG-17 | partial | `BuildConfig.LAB_VISIBLE`: always true for debug; release default true while alpha, `-Pliftoff.lab=false` hides it. Read by `LabGate.visible()` where `SettingsCategories.kt` lists the Lab category. `LabGateTest` pins both settings, the Gradle default and the listing site. `docs/decisions/CFG-17.md` records that the owner flips the default before a public build. Partial until the owner decides. |
