LIFTOFF STUDIO

Runs in your browser. Nothing you change here is sent anywhere; profiles are kept in this browser only. Make a file with Export, then in the app use Backup › Import.

The preview is a drawing made from the settings, not the app. Wallpapers of kind Signal, System and Picture are placeholders. Fonts are bundled under the SIL Open Font License (licences).

PROFILES

    QUICK LOOKS apply to the current profile

    STARTER PROFILES each makes a new profile

    IMPORT

    Where to put it

    EXPORT

    Settings only

    The same file as the app's “Export settings only”. Carries the settings of the six sections, but not the dock settings, corner and gesture actions, ring shortcuts or Comms text size.

    Settings with dock, corners and gestures

    A Backup file that holds the settings and these parts. Importing it changes only these parts; layout, groups and workspaces on the phone are left alone. If the profile came from a full Backup, the rest of that Backup is carried through unchanged.

    In the app: Backup, then Import, then pick the file.

    SHARE LINK

    The link holds the profile after the # sign, so it never goes to a server. Anyone who opens it gets a copy in their own browser. Only what differs from the defaults is in it.
